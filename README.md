# Portfolio Assolin Tecnologia

Site institucional e portfólio profissional da Assolin Tecnologia para apresentação de soluções digitais destinadas a pequenos negócios.

## Stack

- HTML 5
- CSS 3
- JavaScript ES6+
- Vite
- ESLint
- GitHub
- Cloudflare Pages

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```

## Handoff V1

A implementação segue o Figma aprovado `h3k4Vnk6Szt2dOROnbbYOO`, usando:

- cores oficiais: `#0A2240`, `#0F5C6E`, `#263238`, `#E9EEF2`, `#FFFFFF`, `#F59E0B`, `#2E9D68`;
- tipografia: Montserrat para títulos e Inter para textos e interfaces;
- botões com altura mínima de 48 px;
- cards com borda de 8 px e sombra `0 6px 18px rgba(10, 34, 64, 0.1)`;
- menu mobile em overlay;
- FAQ fechado por padrão, com abertura por clique;
- links reais dos cases públicos.
